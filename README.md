# Vikas Thakur | Developer Portfolio

A modern, responsive personal portfolio website showcasing my projects, skills, and resume.

**Live Demo:** [Add your Vercel link here]

## About

This portfolio is built to present my work as an aspiring Frontend / Software Developer. It highlights my projects, technical skills, and provides an easy way to get in touch with me and download my resume.

## Tech Stack

- **React.js** for building the UI
- **Vite** for fast development and optimized builds
- **Tailwind CSS** for styling
- **JavaScript (ES6+)**, **HTML5**, **CSS3**

## Features

- Fully responsive design for mobile, tablet, and desktop
- Clean, modern UI built with Tailwind CSS
- Dedicated sections for projects, skills, and contact
- Downloadable resume
- Fast load times powered by Vite

## Getting Started

```bash
# Clone the repository
git clone https://github.com/VikasThakur-tach/Portfolio.git

# Go to the project folder
cd Portfolio/MyPortfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open `http://localhost:5173` in your browser.
